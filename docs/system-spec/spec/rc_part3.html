  • reset (18804): token+password, סיסמה ≥6 ("טוקן או סיסמה לא תקינים"); טוקן בזיכרון בתוקף שעה ("הקישור לא תקף או שפג תוקפו — בקש קישור חדש").

  2. login: token ZM_{id}_{timestamp}_{random} נשמר ב-Map zoneManagerSessions; מחזיר manager (id, name, email, commission_pct). לקוח שומר zm_token/zm_manager ב-localStorage.
  3. forgot: token ZMR_{id}_... ב-Map zmPasswordResets (תוקף 60 דק'), מייל sendSystemEmail "איפוס סיסמה — WEFLOWZ Zone Manager" עם קישור /zone-manager.html?reset=TOKEN.
