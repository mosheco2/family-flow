  • STORE — Bearer של לקוח חנות (sc-auth, principal_type=storefront). הטלפון והעסק נגזרים מהטוקן.
  • FAMILY — verifyFamily, ובנוסף קישור member_business_links פעיל עם linked_member_ref_id = המנוי.
  • PUBLIC — רק public-types ו-public-schedule (בלי שמות נרשמים), מוצהרים ב-allowlist.

  3. תאריכים: עמודות DATE מוחזרות כמחרוזת 'YYYY-MM-DD' (pg.types.setTypeParser(1082)). כל חישוב קלנדרי נעשה ב-Asia/Jerusalem ובימים קלנדריים. עמודות זמן נקודתי הן TIMESTAMPTZ, והלקוח שולח ISO עם offset (ARC-25).
