כל כרטיס חולץ מכנית מהקוד (server.js): ה-middleware שמופיע ברישום, פרמטרי path, שדות req.query/req.body/req.headers, קודי שגיאה עם ההודעה המילולית, צורת ה-res.json בהצלחה, כל שאילתות ה-SQL שבגוף ה-handler (כולל placeholders), ופונקציות העזר שהוא קורא להן. "ללא middleware" פירושו שאין middleware ברישום. ייתכן שיש בדיקה inline בתוך ה-handler; התיאור המילולי של כל נתיב נמצא בסעיפים במסמך הראשי. "מוצל" פירושו שאותו method+path נרשם קודם, ולכן Express לא מגיע ל-handler הזה.
