חישובים
computeTrendingScore (server.js:40829-40837):
score = (2·likes − 1·dislikes + 3·comments + 5·shares + 4·saves) / (hoursAgo + 2)^1.3
hoursAgo = max(0, (now − published_at)/3,600,000); אם published_at NULL משתמשים ב-now (hoursAgo=0). צפיות לא משתתפות. פריטים מעל 90 יום שומרים את הציון האחרון שלהם לנצח.
