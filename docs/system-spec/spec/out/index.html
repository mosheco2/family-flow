שכבת המפרט לבנייה מחדש. המסמך הראשי מתאר יכולות, זרימות וממצאים. העמודים כאן מוסיפים את הפרטים המדויקים שנחוצים למימוש מחדש, וכולם חולצו מכנית מהקוד: server.js (46,397 שורות) וקבצי הלקוח (כ-104 אלף שורות JS ועוד דפי HTML):
  • חוזה API לכל אחד מ-1511 הנתיבים: middleware, קלטים, שגיאות, תשובה ו-SQL מלא.
  • מילון נתונים של כל הטבלאות והעמודות, עם מקור כל עמודה.
  • מפרט מסכים לכל ארבע הסביבות: קבועי תצורה (ניווט, מודולים לפי סוג עסק, מינוח), מסכים סטטיים, וכל פונקציית רינדור עם שדות הטופס, הכפתורים וקריאות ה-API שלה, כולל קישור לחוזה בשרת.
  • לוגיקה עסקית ב-13 תחומים, 667 תהליכים: טריגרים, אימותים, סדר פעולות, נוסחאות, מכונות מצבים, תופעות לוואי והתנהגות ממשק.
  • שכבת אפיון: מילון מונחים, מטריצת הרשאות, מודולים לפי סוג עסק, מודל ישויות (ERD), קטלוג הודעות, קטלוג פרומפטים של AI, נתוני ברירת מחדל, והשוואה בין מסמכי האפיון הקיימים לקוד.
  • קטלוג פונקציות עזר.
  • תשתית: middleware גלובלי, תהליכי רקע, משתני סביבה ותלויות.
