תנאים ואימותים
  • name, code, city חובה — אחרת 400 "שם, עיר וקוד קהילה הם שדות חובה" (17497).
  • code נשמר toUpperCase().trim(); כפילות (PG 23505) → 400 "קוד הקהילה שבחרת כבר קיים במערכת. אנא בחר קוד אחר." (17508).
  • managerEmail ברירת מחדל system@weflowz.co.il, managerPassword ברירת מחדל '' (17494) — שדות לגאסי, לא משמשים לכניסה בשום מקום בקוד.

ממשק

פערים

תחומי עניין, סוג קהילה, גילוי קהילות ודירוג התאמה לעסק

מטרה וטריגר
SA מגדיר תגיות וסוג; משפחה מחפשת קהילות; עסק רואה התאמה.
תנאים ואימותים
  • POST /api/sa/communities/:id/interests (21317): tags חייב להיות מערך (400 "tags חייב להיות מערך").
  • POST /api/sa/communities/:id/type (21407): רק geographic|interest (400 "סוג לא חוקי").
שלבי עיבוד
  1. interests: communities.interest_tags = tags.join(','); DELETE+INSERT community_interests.
  2. discover (ציבורי, 21358): status='active'; q (ILIKE על שם/עיר/שם אזור) גובר על city; type; LIMIT 50 ממוין family_count; מחזיר גם byCity (עיר ריקה → 'ארצי'). מחזיר code (מאפשר הצטרפות ישירה).
  3. by-interest (ציבורי, 21341): ILIKE על interest_tag.
  4. match (GET /api/biz/communities/match/:bizId 21194).
חישובים
ציון התאמה (21220–21248), תקרה 100, מעוגל:
  • מיקום 0–40: אם לעסק location_lat/lng ולקהילה lat/lng: dist = √(Δlat²+Δlng²)·111; max(0, 40 − 4·dist). אחרת התאמת עיר מלאה +35, חלקית (includes) +20.
  • עסקים: min(20, biz_count·2). משפחות: min(30, family_count·0.5).
  • תגית: +10 אם interest_tags כולל מילה ממפה: beauty→[יופי,קוסמטיקה,ספא], sport→[כושר,ספורט], food→[אוכל,מסעדה,קייטרינג], logistics→[שירותים,לוגיסטיקה].
ממשק
app.js:openCommunityDiscoveryModal (7943), searchCommunitiesByCity (8012); business-app.js:loadBizCommunitiesWithMatch (17600).
פערים
