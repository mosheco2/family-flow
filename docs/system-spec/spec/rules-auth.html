סשן משפחה/עסק — family_sessions (יצירה, מבנה, ביטול)

מטרה וטריגר
טוקן גישה יחיד לסביבות FAMILY ו-BIZ. נוצר בכל זרימת התחברות/הרשמה מוצלחת: /api/login (server.js:10706), /api/family/login/password (10605), /api/biz/register (8151), /api/biz/login (8200), POST /api/groups ל-FAMILY בלבד (10211), /api/community/bootstrap-token (10733), /api/family/sso-login (43827), ו-SA impersonation (44034, INSERT ישיר).
תנאים ואימותים
  • הטבלה: token_hash CHAR(64) PK, group_id FK→family_groups ON DELETE CASCADE, user_id FK→users ON DELETE CASCADE, created_at, last_seen, expires_at, device_hint VARCHAR(100) (server.js:41809-41818); עמודה session_type VARCHAR(20) DEFAULT 'family' נוספת ב-ALTER (516). אינדקסים על expires_at, group_id (41819-41820).
  • מחיקת משתמש/קבוצה מוחקת את כל הסשנים שלו (CASCADE).
שלבי עיבוד
  1. createFamilySession(groupId, userId, deviceHint=null, sessionType='family') (41853): rawToken = randomBytes(32).hex (64 תווים).
  2. tokenHash = sha256(rawToken).hex (_hashToken, 41849).
  3. expires_at = now + 30 ימים (41856).
  4. INSERT ל-family_sessions עם device_hint חתוך ל-100 תווים (41857-41861). מוחזר הטוקן הגולמי בלבד; ה-DB שומר רק hash.
  5. destroyFamilySession(rawToken) — DELETE לפי hash (41865). destroyAllFamilySessions(groupId) (41871) — מוגדרת אך לא נקראת בשום מקום.
חישובים
תוקף 30 יום קבוע (לא sliding — last_seen מתעדכן אך expires_at לא מוארך). Impersonation: שעה (44035). session_type: 'biz' אם family_groups.type='BUSINESS' ב-/api/login (10706); תמיד 'family' ב-/api/family/login/password (10605); 'biz' ב-register/login עסקי; ב-impersonation 'family' אם type=FAMILY אחרת 'biz' (44019).
מכונת מצבים
סשן: קיים-תקף → פג (expires_at<now; נמחק עצלנית ב-middleware או בקרון יומי) → נמחק (logout / cron / CASCADE).
תופעות לוואי
אין.
פערים
  • שינוי/איפוס סיסמה אינו מבטל סשנים קיימים (destroyAllFamilySessions מת).
  • impersonation עם קבוצה ללא משתמשים מכניס user_id=0 (44028) → הפרת FK → 500.
