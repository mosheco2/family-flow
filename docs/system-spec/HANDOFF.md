# HANDOFF: אפיון מערכת WEFLOWZ / family-flow

המסמך הזה מאפשר להמשיך את העבודה מסשן חדש בדיוק מאותה נקודה.
**הוראה לסשן החדש:** לקרוא קודם את הקובץ הזה, אחר כך את `CLAUDE.md`, ואז להמשיך מסעיף "השלב הבא".

## כללים קבועים מהמשתמש
- כל תשובה בעברית.
- **לא משנים קוד במערכת.** עובדים רק על התיעוד והאפיון. התיקייה הזו (`docs/system-spec/`) היא תיעוד בלבד.
- **כלל העל לאפיון היעד:** שומרים על מהות המערכת ועל כל יכולת ופעולה שקיימות היום. מתקנים את מה שבור, מאבטחים את מה שפתוח, ומאחדים את מה שכפול. אף פעם לא מסירים יכולת ולא מצמצמים אותה.
- המשתמש אישר את כל 671 ההחלטות באישור גורף, וביקש לוודא שהאפיון מייצג את כל המערכת מקצה לקצה בלי לפגוע במהות.
