איך זה עובד. הפריטים נאספו מ-13 תחומים ומהארכיטקטורה הרוחבית. פריטים שחזרו בכמה תחומים אוחדו לכרטיס אחד, ובכרטיס כזה מופיעה השורה "אוחד עם". כל כרטיס הוא פער שנמצא בקוד הקיים. בכל כרטיס מופיע מה הקוד עושה היום ("כיום"), ומה מוצע שיהיה הכלל הנכון במערכת החדשה ("הצעה"). לכל כרטיס אפשר לבחור אחת מהאפשרויות: לאשר את ההצעה, לבחור חלופה, לכתוב כלל אחר, לסמן "מחוץ להיקף" (הפיצ'ר לא ייבנה), או לדחות לדיון. ההחלטות נשמרות אוטומטית, ו-Claude קורא אותן וממזג אותן לעמודי הלוגיקה, כך שהמסמך הופך לאפיון. מומלץ להתחיל בסינון "קריטי".
