# צ'ק-ליסט בדיקה ידנית — "שוקה"

> מטרה: לוודא שהזרימה המלאה עובדת מקצה לקצה בסביבת הפרודקשן, אחרי כל הדיפלוי של 5 הקומיטים.
> **הערה:** לא בוצעה בדיקה אוטומטית/בדפדפן מצד Claude — אין גישת רשת מהסביבה הזו לאתר החי או ל-DB. כל הבדיקות כאן ידניות.
> מומלץ לבדוק **בסדר הזה בדיוק** (כל שלב תלוי בקודם).

דרוש מראש: חשבון עסק קיים שחבר בקהילה (למשל "פיצה מושיק" בקהילת "נוקדים אל דויד"), חשבון מנהל-קהילה או מנהל-אזור לאותה קהילה, חשבון SA, וקמפיין "שוקה" קיים (אפשר ליצור חדש דרך מנהל הקהילה אם אין).

| 6.5 | בדוק את המוצר שהוזל במחיר (4.4) | | מוצג עם קו-חוצה על המחיר המקורי + תג "מחיר שוק ✨" |

| 6.8 | אם קיים מוצר מסוג `complex_builder` (מנה מורכבת/קומבו) | | כפתור "📋 צפייה במפרט"; לחיצה פותחת מודל רב-שלבי עם כל השלבים/אפשרויות מהגדרת המוצר האמיתית בעסק |
| 6.9 | במודל `complex_builder` — בחר אפשרויות בכמה שלבים ובדוק שהמחיר המוצג בכפתור "הוספה לעגלה" מתעדכן בזמן אמת | | כן |

| 6.12 | נסה להוסיף מוצר מעסק **שני** לאותה עגלה | | הודעה "אפשר להזמין רק מעסק אחד" — העגלה לא מתערבבת |
| 6.13 | התחבר כלקוח (OTP/הרשמה) והשלם הזמנה הכוללת את המוצר המורכב מ-6.11 | | **זו הבדיקה הכי קריטית** — זה בדיוק התרחיש שבו היה הבאג שתוקן (אימות מחיר שרת לפריטים עם תוספות). ההזמנה אמורה **להצליח**, לא לחזור עם "מחיר פריט אינו תקין" |
