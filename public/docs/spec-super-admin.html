מפרט טכני — סביבת Super Admin

OneFlow Life · SA Environment · גרסה 2026-06-20

מסמך זה מתאר את מלוא הפונקציונליות של סביבת ה-Super Admin — מרכז הבקרה המרכזי של מערכת Oneflow Life. הסביבה מאפשרת ניהול כלל הקבוצות, העסקים, הקהילות, הצוות, הפיננסים, ומוצרי הפלטפורמה. נכתב על בסיס קריאת קבצי המקור: sa.html, sa-app.js, server1.js.

URL: /sa.html Node.js / Express PostgreSQL Vanilla JS + TailwindCSS 15 טאבים 7 קבוצות ניווט

  • משימה עוברת in_progress → qa  → התראה "ממתין לבדיקה"

13. Impersonation Mode

SA לוחץ "Impersonate" על קבוצה
          ↓
impersonateGroup(groupId, userId)
          ↓
חיפוש קבוצה + משתמש מנהל
          ↓
שמירת SA token: localStorage('ofl_sa_return_token')
          ↓
הסרת 'ofl_sa_token' מ-localStorage
          ↓
יצירת session: { user: targetUser, group: targetGroup, isImpersonating: true }
          ↓
localStorage('ofl_session') ← session חדש
          ↓
פתיחה בטאב חדש: /business.html (עסק) / / (משפחה)
          ↓
אחרי 2 שניות: שחזור SA token → 'ofl_sa_token'
פס אדום: מוצג בסביבת BIZ/FAMILY (לא ב-SA). סביבות היעד בודקות ofl_session.isImpersonating.
יציאה: סגירת הטאב החדש. ה-SA session שוחזר אוטומטית אחרי 2 שניות מרגע הכניסה.
