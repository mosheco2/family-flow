1.3 מי משתמש בסביבה

Zone Manager = מנהל אזור

  • ▸ אחראי על אזור גיאוגרפי הכולל מספר קהילות שכונתיות
  • ▸ מגייס משפחות ועסקים לפלטפורמה דרך קמפיינים
  • ▸ מפקח על קהילות, ממנה מנהלי קהילה מקומיים
  • ▸ מרוויח עמלה (ברירת מחדל: 5%) על פעילות בקהילות שלו

8 קמפיינים — Flow מלא

8.1 זרימה מלאה — יצירה עד שליחה ב-WhatsApp

1. ZM יוצר קמפיין (modal)
   → POST /api/zone-manager/campaigns
   → DB: zm_campaigns (token = UUID)

2. ZM לוחץ "ווצאפ"
   → נפתח: https://wa.me/?text=ENCODED
   → הטקסט: שורה ראשונה מהקמפיין + 👉 /c/camp/TOKEN

3. WhatsApp מבצע crawl לנתיב /c/camp/TOKEN
   → Server מחזיר HTML עם OG meta tags
   → og:title, og:description, og:image

4. משתמש מקבל כרטיס preview ב-WhatsApp
   → לוחץ → נכנס ל-/c/camp/TOKEN
   → http-equiv=refresh → מועבר ל-/campaign.html?t=TOKEN

5. campaign.html
   → GET /api/public/campaign/TOKEN
   → מציג כותרת + תמונה + טקסט + שדות טופס

6. ממלא טופס + שולח
   → POST /api/public/campaign/TOKEN/submit
   → DB: zm_campaign_leads

7. ZM רואה ליד בטאב לידים
   → ניתוח AI → עדכון CRM → מעקב

9 סביבת קהילה (Community)

9.1 מהי קהילה ב-OneFlow

קהילה = ישות ארגונית שכונתית / גיאוגרפית

שדות:

  • id, name, city
  • code (קוד הצטרפות 4-6 תווים)
  • zone_id (אזור גיאוגרפי)
  • status: pending / active
  • image_url (אופציונלי)

טבלאות DB:

  • communities
  • family_communities
  • community_businesses
  • manager_zones

9.4 זרימת הצטרפות עסק לקהילה (3 שלבים)

9.5 מנהל קהילה מקומי (Community Manager)

  • ▸ ממונה על ידי Zone Manager מחברי הקהילה
  • ▸ is_community_manager=TRUE ב-family_communities
  • ▸ מקבל ושולח הודעות ב-inbox קהילתי
  • ▸ יכול לאשר/לדחות בקשות עסקים
  • ▸ GET /api/community/manager-data/:groupId — נתוני ניהול מלאים
