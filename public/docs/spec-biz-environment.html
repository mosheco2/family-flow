6 מודולים — תיאור מלא

6.1 הזמנות — Order Status Flow

new → processing → ready → shipped → delivering → completed | cancelled

ציר זמן (5 תחנות):

  1. הזמנה התקבלה במערכת
  2. בטיפול / בהכנה
  3. מוכנה לאיסוף (עצמי / שליח)
  4. יצאה למשלוח / נאספה
  5. סופקה ללקוח / הושלמה

6.3 סיכום מודולים מרכזיים

💰

קופה (POS)

קטגוריות מוצרים + חיפוש, סל קנייה, Modifiers, זיהוי לקוח לפי טלפון, הנחה %, %, מסך מלא, סריקת ברקוד, תשלום: מזומן/אשראי/ספליט

⏱️

נוכחות (timeclock)

החתמה GPS (150מ'), דוח חודשי, ייצוא PDF, דיווח ידני, שעות מצטברות. API: punch, status, report, manual, set-location

✅

משימות (tasks)

סטטוסים: pending/done/approved/cancelled. AI generate, Vision verify. עובד ← מנהל, self-task, הוכחה צילום

🎓

הכשרות (academy)

חבילות לימוד + חידונים, שיוך לעובד, AI generate bundle, מורה AI (tutor), ציוני עובדים

🔧

ציוד (equipment)

פריטים + תחזוקה + תקלות + טכנאים. תאריך אחריות עם התראה, badge count על טאב, תכניות תחזוקה תקופתיות

💳

כספים (bank)

הכנסות/הוצאות, קטגוריות, הלוואות (request/approve/reject), יעדים, AI insight
