# אפיון Marketplace — שוק מטבעות FLW
מסמך אפיון · OneFlow Life · עודכן 24.08.2026

---

## סקירה כללית

`marketplace.html` — מרקטפלייס ציבורי לחברי OneFlow. מאפשר קנייה/מימוש מוצרים ושירותים תמורת מטבעות FLW (FlowPoints) או תשלום כספי. קהל יעד: חברי קהילה שצברו FLW דרך פעילות במערכת.

---

## ארכיטקטורה

- **עיצוב:** Tailwind CSS, גופן Assistant
- **פלטת צבעים:** ירוק כהה `#1F4D3D` (brand), חול/אפור `#E9E7E2`
- **מותג:** `.flw-badge` — סמל המטבע

---

## CSS Variables

| Variable | ערך | תפקיד |
|---|---|---|
| `--green` | `#1F4D3D` | צבע ראשי |

| `--discount-bg` | `#E8F5EE` | רקע תגי הנחה |
| `--discount-text` | `#1F4D3D` | צבע טקסט הנחה |

## Header (Sticky)

| אלמנט | תפקיד |
|---|---|
| `.flw-badge` | יתרת FLW של המשתמש |
| `.icon-btn` (פעמון) | התראות |
| `.icon-btn` (סל) | עגלת קניות |
| input חיפוש | `.search-bar` |
| `.filter-chips` | סינון קטגוריות (scroll אופקי) |

---

## כרטיס יתרה (`.flw-banner`)

- הצגת יתרת FLW נוכחית
- כפתור מימוש (`flw-redeem-btn`)
- מידע על ערך המטבע

---

## קטגוריות (Filter Chips)

| קטגוריה | דוגמאות |
|---|---|
| הכל | כל המוצרים |
| מוצרים | ספרים, ציוד |
| שירותים | ייעוץ, הדרכה |
| חוויות | אירועים, סיורים |
| דיגיטל | קורסים, תכנים |

---

## כרטיסיית מוצר (`.product-card`)

| שדה | תפקיד |
|---|---|
| תמונה | תמונת המוצר |
| כותרת | שם המוצר |
| תיאור | תיאור קצר |
| תג הנחה | אחוז חיסכון בFLW |
| מחיר FLW | עלות במטבעות |
| מחיר ₪ | עלות כספית חלופית |
| כפתור | "רכוש" / "מימוש" |

---

## מצבי רכישה

| מצב | תיאור |
|---|---|
| FLW מלא | מימוש ב-FLW בלבד (אם יש מספיק) |
| מעורב | חלק FLW + חלק תשלום כספי |
| כספי בלבד | ₪ בלבד ללא מטבעות |

---

## API Calls (צפוי)

| Method | Endpoint | תפקיד |
|---|---|---|
| GET | `/api/marketplace/products` | טעינת מוצרים |
| GET | `/api/marketplace/balance` | יתרת FLW |
| POST | `/api/marketplace/purchase` | רכישה/מימוש |
| GET | `/api/marketplace/categories` | קטגוריות |

---

## Session

- משתמש מזוהה דרך `ofl_session` (localStorage)
- אורחים: יכולים לדפדף, לא לרכוש
- `token` נשלח בheader לכל קריאה מאומתת
