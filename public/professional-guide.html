👔 מדריך עסק מקצועי / ייעוץ

מדריך מקיף לניהול עסק מקצועי — עורכי דין, רואי חשבון, יועצים עסקיים, מנהלים, מטפלים, אדריכלים, מעצבים, יחסי ציבור, פסיכולוגים, מאמנים ועוד.

15 מודולים מודל תיקים מקצועי דיווח שעות מדויק אתר ציבורי + מאמרים
🚀

התחלה מהירה — 5 צעדים

1
צור עסק מסוג "מקצועי / ייעוץ"ONEFLOW → צור קבוצה → עסק → בחר "מקצועי / ייעוץ". הגדר שם, לוגו ותחום התמחות.
2
הגדר שירותים וקטלוגמכירות → שירותים → הוסף שירותים עם תמחור (שעתי, קבוע, לפי פרויקט).
3
הוסף לקוח ראשוןלקוחות → לקוח חדש → הזן שם, טלפון, דוא"ל. ניתן לייבא מרשימה קיימת.
4
שלח הצעת מחירמכירות → הצעות → הצעה חדשה → בחר לקוח, הוסף שירותים, שלח ב-PDF / WhatsApp.
5
המר לתיק ופתח עבודהבהצעה שאושרה → "המר לתיק" → נפתח תיק עם יומן, מסמכים ומשתתפים.
💡 טיפ: הויזארד ינחה אותך צעד אחר צעד בהקמה הראשונית — לא תצטרך להגדיר הכל ידנית.

CRM — ניהול לקוחות

לקוחות הוא לב המערכת — כל תיק, הצעה, יומן ומסמך מקושר ללקוח.

1
הוספת לקוח חדשלקוחות → + לקוח חדש → שם, טלפון, דוא"ל, כתובת, הערות.
2
כרטיס לקוחלחץ על לקוח → רואה: תיקים פתוחים, היסטוריית תיקים והצעות, פגישות, מסמכים, הערות.
3
חיפוש וסינוןחפש לפי שם / טלפון / דוא"ל. סנן לפי תגיות, סטטוס פעיל/לא פעיל.
💡 היסטוריה בכרטיס לקוח: הלשונית "תיקים והצעות" מציגה את כל הפעילות של הלקוח — תיקים פתוחים, הצעות שנשלחו, תשלומים.
🎯

לידים — לקוחות פוטנציאליים

לידים מגיעים אוטומטית מהאתר הציבורי (טופס יצירת קשר) או נוספים ידנית.

1
לידים מהאתרמישהו מילא טופס ביצירת קשר באתר שלך → מופיע אוטומטית ברשימת הלידים.
2
לידים ידנייםלידים → + ליד חדש → שם, טלפון, צורך, מקור (המלצה / פרסום / רשת חברתית).
3
המרה ללקוחכשהליד אושר → "המר ללקוח" → נוצר כרטיס לקוח אוטומטית עם כל הפרטים.
מעקב ליד: ניתן לסמן סטטוס — חדש / יצרנו קשר / בתהליך / סגור (הצלחה/כישלון). זה עוזר לראות מה קורה עם כל ליד.
📰

פיד — לוח בקרה ועדכונים

הפיד הוא הלשונית הראשית — רואים עדכונים, התראות, קיצורי דרך לפעולות נפוצות.

  • התראות על תיקים דחופים או עם תאריך יעד קרוב
  • פגישות היום ומחר
  • משימות שנפתחו ומשימות שפג תוקפן
  • לידים חדשים שהגיעו מהאתר
  • עדכונים על הצעות שנפתחו על ידי לקוחות

3
המרה לתיקכשהלקוח אישר ← "המר לתיק" ← נפתח תיק מקצועי אוטומטית.

תיקים — ניהול פרויקטים מקצועיים

התיק הוא יחידת העבודה המרכזית בעסק מקצועי. כל פרויקט / לקוח / נושא מנוהל כתיק נפרד.

מה יש בתיק?

לשוניתמה רואים
סקירהפרטי התיק, סטטוס, תאריכי פתיחה/יעד, שכר טרחה
משתתפים 👥אנשי צוות השייכים לתיק, שעות וביצועים
מסמכיםחוזים, נספחים, תוצרים — לפי תיק
הערות תיקהערות פנימיות לצוות (לא גלויות ללקוח)
פגישה ויומןתזמון פגישות מחוברות לתיק
היסטוריית תיק 📋ציר זמן של כל הפעולות: פגישות, מסמכים, שינויי סטטוס
עלויותשעות עבודה בתיק, שכר טרחה/הכנסה, רווחיות צפויה

כיצד פותחים תיק?

1
מהצעת מחיר (מומלץ)מכירות → הצעות → בהצעה מאושרת → "המר לתיק" → תיק נפתח עם כל פרטי הלקוח.
2
ישירות מרשימת התיקיםמכירות → תיקים 📁 → + תיק חדש → בחר לקוח, הגדר נושא ותאריך.

ניהול שוטף של תיק

  • הוסף משתתפים — בחר מהצוות, הגדר תפקיד בתיק
  • תזמן פגישה — לחץ "פגישה ויומן", הפגישה נרשמת ביומן ואצל כל המשתתפים
  • העלה מסמכים — חוזים, תוצרים, פרוטוקולים
  • דווח שעות — ממסך דיווח שעות עם ציון מספר התיק
  • עקוב אחרי רווחיות — בלשונית "עלויות": שעות × תעריף מול שכר טרחה
💡 סטטוס תיק: פתוח / בטיפול / ממתין ללקוח / סגור. ניתן לסנן את רשימת התיקים לפי סטטוס.
📄

מסמכים

ניהול מסמכים מקצועיים — חוזים, הצהרות, טפסים, תוצרים — כולם מקושרים לתיק ולקוח.

1
תבניות מסמכיםמסמכים → תבניות → צור תבנית עם שדות דינמיים (שם לקוח, תאריך, סכום). שמור לשימוש חוזר.
2
מסמך לפי לקוח / תיקבתוך תיק → לשונית מסמכים → + מסמך → המערכת ממלאת פרטי לקוח אוטומטית.
3
הורדה ושליחההורד כ-PDF, שלח ישירות ב-WhatsApp / דוא"ל לחתימה.
דוגמאות לתבניות: חוזה שירות, הסכם סודיות (NDA), אישור קבלת פרויקט, דוח עבודה חודשי, פרוטוקול ישיבה.
📅

יומן ופגישות

יומן עסקי מרכזי — מציג פגישות, אבני דרך בתיקים, ומשימות בעלות תאריך יעד.

1
קביעת פגישה מהיומןיומן → לחץ על שעה ריקה → בחר לקוח / תיק → הגדר נושא ומשך.
2
קביעת פגישה מתוך תיקבתיק → "פגישה ויומן" → תזמן פגישה → הזימון נרשם ביומן ואצל כל משתתפי התיק.
3
תזכורותהמערכת שולחת תזכורת אוטומטית לפני פגישה לפי הגדרת הזמן שתבחר.
💡 צבעים ביומן: כל סוג אירוע מוצג בצבע שונה — פגישה עם לקוח, משימה פנימית, אבן דרך בתיק.
⏱

דיווח שעות

מודול מרכזי לעסק מקצועי — מאפשר לעקוב אחרי שעות עבודה לפי תיק ועובד.

1
דיווח שעות ידנידיווח שעות → + רשומה → בחר תיק, תאריך, שעות, תיאור העבודה.
2
טיימרלחץ ▶ כדי להתחיל טיימר בזמן אמת → בסיום לחץ ⏹ → השעות נרשמות אוטומטית.
3
דוח שעותראה סה"כ שעות לפי תיק, לפי עובד, לפי תקופה. שמש לחישוב שכר טרחה.
מה רואיםאיפה
שעות לפי תיקבתוך התיק → לשונית עלויות
שעות לפי עובדדיווח שעות → סנן לפי עובד
שעות לפי תקופהדיווח שעות → סנן לפי חודש
רווחיות תיקתיק → עלויות → שעות × תעריף מול שכר טרחה
כיצד עובד החישוב: שעות עבודה × תעריף שעתי של העובד = עלות תיק. שכר טרחה ללקוח - עלות תיק = רווח צפוי.
⏰

שעון נוכחות

שעון נוכחות פשוט — כניסה ויציאה לעבודה, שונה מדיווח שעות לתיק.

1
כניסה לעבודהשעון נוכחות → "כניסה" → רושם שעה + מיקום (אופציונלי).
2
יציאהשעון נוכחות → "יציאה" → רושם שעה ומחשב סה"כ שעות יום.
3
דוח נוכחותשעון נוכחות → היסטוריה → ראה נוכחות לפי עובד ולפי חודש.
ההבדל: שעון נוכחות = מתי הגעת/יצאת. דיווח שעות = כמה שעות עבדת על כל תיק ספציפי.
✅

משימות

ניהול משימות — יכולות להיות קשורות לתיק ספציפי או כלליות.

1
משימה חדשהמשימות → + משימה → כותרת, תאריך יעד, שייך לעובד, קשר לתיק (אופציונלי).
2
מעקב סטטוסלא התחיל / בתהליך / הושלם. ניתן לסנן לפי סטטוס ועובד.
3
תזכורותקבל התראה כשמשימה מתקרבת לתאריך יעד או פגה.
💰

תזרים מזומנים

סקירה פיננסית של העסק — הכנסות, הוצאות, רווח נקי לפי תקופה.

  • הכנסות מתיקים ושכר טרחה
  • הוצאות כגון: משכורות, שכירות, ציוד, תוכנות
  • גרף תזרים חודשי / רבעוני / שנתי
  • השוואה בין תקופות
  • ייצוא לאקסל לרואה חשבון
💡 שימוש: בדוק בסוף כל חודש — האם ההכנסות מכסות את ההוצאות? כמה תיקים פתוחים ומה הצפי שלהם?
📋

תקציב

תכנון תקציבי — הגדר יעד הכנסות ותקציב הוצאות לכל קטגוריה.

1
הגדר יעד הכנסה חודשיתקציב → הכנסות → הזן יעד. המערכת תמדוד את ההשגה בפועל.
2
הגדר תקציב הוצאותלפי קטגוריה: כוח אדם, שיווק, תפעול, ציוד. קבל התראה כשמתקרבים לתקרה.
3
מעקב ביצועבכל חודש — ראה תקציב מול ביצוע בפועל לכל קטגוריה.
🏦

חשבון בנק

חיבור לחשבון הבנק לצורך מעקב תנועות ופיוס עם הרשומות במערכת.

  • ייבוא תנועות בנק מקובץ CSV (ממרבית הבנקים בישראל)
  • סיווג תנועות: הכנסה / הוצאה / העברה
  • התאמה בין תשלום שהתקבל בבנק לבין תיק ספציפי
  • מעקב יתרה שוטפת
👥

ניהול צוות

הוסף עמיתים, שותפים, ועוזרים לעסק ושייך אותם לתיקים.

1
הזמנת איש צוותצוות → + הזמן → הזן דוא"ל → בחר תפקיד (מנהל / עוזר / נותן שירות).
2
שיוך לתיקיםבכל תיק → משתתפים → + הוסף משתתף → בחר מהצוות.
3
עלות עובדהגדר תעריף שעתי לכל עובד — ישמש לחישוב עלות תיק מול שכר טרחה.
עובד חיצוני / פרילנסר: ניתן להוסיף ולשייך לתיק ספציפי בלבד, ללא גישה לשאר הנתונים.
🌐

אתר ציבורי — חזית העסק

האתר הציבורי של העסק שלך — גלוי לכולם, ממותג לעסק שלך, כולל 4 אזורים עיקריים.

אזורמה מציגכיצד לערוך
עמוד ראשישם העסק, תיאור, שירותים מרכזייםתוכן → עמוד ראשי
תחומי מומחיותרשימת תחומי ההתמחות שלךתוכן → מומחיות
מאמריםמאמרי בלוג / עמדות מקצועיות / מדריכיםתוכן → מאמרים → פרסם
יצירת קשרטופס שליחת הודעה → מגיע אליך כלידאוטומטי
💡 הגדרת כתובת האתר: הגדרות העסק → כתובת ציבורית. הלינק ניתן לשיתוף בכרטיס ביקור, אינסטגרם, לינקדאין.
📝

מאמרים ובלוג מקצועי

פרסם מאמרים, תובנות, עמדות מקצועיות — מציגים באתר הציבורי שלך ובונים מוניטין.

1
כתיבת מאמר חדשתוכן → מאמרים → + מאמר חדש → כותרת, תמצית, תוכן, תמונה ראשית.
2
פרסוםשמור כטיוטה ← ערוך ← "פרסם" ← מופיע מיידית באתר הציבורי.
3
תצוגה בציבורהמבקרים באתר רואים עד 3 מאמרים אחרונים. לחיצה על מאמר פותחת אותו לקריאה מלאה.
למה לפרסם מאמרים? בונה אמינות מקצועית, משפר חשיפה בגוגל, מעודד לידים להשאיר פרטים אחרי קריאה.

ניהול תוכן

  • שינוי שם העסק, סלוגן, תיאור
  • העלאת לוגו ותמונת כיסוי

  • עריכת אזור "אודות" ו"צור קשר"
  • ניהול תחומי מומחיות ומיומנויות

תסריטי שימוש — יום רגיל בעסק

כיצד נראה יום עבודה טיפוסי בעסק מקצועי עם ONEFLOW?

🌅 בוקר — בדיקת מצב

פיד → רואה: פגישות היום, משימות דחופות, לידים חדשים מהאתר. יומן → מוודא שכל הפגישות ביומן.

📞 ליד חדש הגיע

לידים → פרטי הליד (הגיע מאתר) → יצירת קשר → קביעת שיחת היכרות ביומן → אחרי שיחה: המרה ללקוח + שליחת הצעת מחיר.

📄 לקוח אישר הצעה

מכירות → הצעות → "המר לתיק" → שמות פרטי הלקוח → הוסף משתתפים → תזמן פגישת קיקאוף ביומן.

⏱ עבודה על תיק

דיווח שעות → בחר תיק → הפעל טיימר → עבוד → עצור. או: דווח ידנית שעות בסוף היום עם תיאור מה נעשה.

📋 סיום פרויקט

תיק → שנה סטטוס ל"סגור" → צור מסמך סיכום → שלח ללקוח → בדוק לשונית "עלויות" לראות רווחיות סופית.

📊 סוף חודש

תזרים → ראה הכנסות vs. הוצאות החודש. תקציב → בדוק ביצוע מול יעד. דיווח שעות → ייצא דוח לחישוב שכר.

📝 שיווק ותוכן

תוכן → מאמרים → כתוב מאמר מקצועי → פרסם. מופיע אוטומטית באתר. שתף לינק בלינקדאין / אינסטגרם.

❓

שאלות נפוצות

מה ההבדל בין תיק לפרויקט?
תיק הוא המינוח שמשתמשים בו ב-ONEFLOW לסוג העסק "מקצועי / ייעוץ". הוא זהה לפרויקט — כולל יומן, מסמכים, משתתפים ומעקב שעות. מתאים לעורך דין, יועץ, מטפל, אדריכל וכל נותן שירות מקצועי.
איך מחשבים רווחיות תיק?
בתוך התיק → לשונית "עלויות". המערכת לוקחת את שעות העבודה שדווחו × התעריף השעתי של כל עובד = עלות. שכר הטרחה שהגדרת בהצעה - עלות = רווח צפוי. ניתן לראות אחוז רווח.
האם לקוחות יכולים לראות את התיק?
לא. התיקים הם פנימיים לצוות שלך. הלקוחות מקבלים: הצעת מחיר, מסמכים ספציפיים שתשלח אליהם, וגישה לאתר הציבורי שלך.
כיצד מגיעים לידים מהאתר?
באתר הציבורי שלך יש טופס "צור קשר". כשמישהו ממלא אותו — הפרטים מגיעים אוטומטית ל"לידים" במערכת עם כל המידע שהזין. לא צריך לעשות כלום — מגיע לבד.
מה ההבדל בין דיווח שעות לשעון נוכחות?
שעון נוכחות = שעת הגעה ויציאה מהעבודה (כמו כרטיס עובד). דיווח שעות = על איזה תיק עבדת ובמשך כמה זמן (לצורך חיוב לקוח וחישוב רווחיות).
כיצד מוסיפים תחומי מומחיות לאתר?
תוכן → עמוד ראשי → אזור מומחיות → + הוסף תחום → כתוב שם ותיאור קצר. מופיע מיידית באתר הציבורי.
האם ניתן לנהל כמה לקוחות במקביל?
כן, בלי הגבלה. כל לקוח יכול להיות בו-זמנית בתיקים מרובים, עם נותני שירות שונים. כל תיק עצמאי, עם יומן, שעות ומסמכים נפרדים.
כיצד מייצאים נתונים לרואה חשבון?
תזרים → ייצוא CSV. דיווח שעות → ייצוא. ניתן לסנן לפי תאריך ולייצא בדיוק את הטווח שצריך. הקובץ נפתח ב-Excel ישירות.
