מה זה OneFlow Life?

מערכת ניהול חכמה המחברת בין משפחות, עסקים, קהילות וניהול מערכת, הכל בממשק אחד משותף.

3 סביבות נפרדות לגמרי:

  • 🏠 FAMILY — לניהול משפחתי (index.html)
  • 🏪 BIZ — לניהול עסקים (business.html)
  • 👥 ADMIN — לניהול קהילות (admin.html)

Backend: Node.js + Express + PostgreSQL

👥 סביבת ADMIN

קהילות + Super Admin

קהילה = קבוצת משפחות וגם עסקים (לדוגמה "קהילת שכנים")

יכולות קהילתיות:

  • סקרים קהילתיים
  • אירועים (כנסים, קניות משותפות)
  • צ'אט וצ'צוקים
  • ניהול חברים

🎯 OneFlow Life בקיצור

  • 👨‍👩‍👧 FAMILY: תקציב ילדים + PayDay + מלאי + משימות
  • 🏪 BIZ: קופה + עובדים + לקוחות + כספים
  • 👥 ADMIN: קהילות + סקרים + אירועים

כל אחד בנפרד, כל אחד בעיצוב משלו, אבל נתונים מחוברים = סה"כ אקוסיסטם.
